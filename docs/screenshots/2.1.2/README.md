# Movinite 2.1.2 screenshots

These shots use a 1920×1080 television layout on a test library with placeholder posters and made-up names. Documentation addresses use `192.0.2.10`.

- `tv-home.png` — Plex-style TV home. The web header is hidden. The tab bar and clock are transparent over the backdrop.
- `tv-menu-signout.png` — slide-out menu open, profile expanded, Sign out focused.
- `tv-details-play.png` — movie page opened from the home row, scrolled to the top, with Resume or Play focused and on screen.
